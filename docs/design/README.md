# Пакет для работы над визуальным дизайном

Всё, что требуется передать в среду подготовки оформления. Доступа к репозиторию у неё нет: файлы переносятся вручную, автоматически ничего не подтягивается.

Файлы `03`, `08`, `09` и `12`–`16` описывают решения версий до 0.7.0 (кнопка «Закончить день», ползунки в плане и копилке) и сохранены как история проектирования; актуальная структура экранов версии 0.9.0 — `04-screens.md`.

Сами выгрузки среды оформления — рабочий промежуточный материал и в репозиторий не включены. Разбор каждой и перенесённые в код решения записаны в файлах `08`–`16`.

## Порядок использования

1. Загрузить все файлы каталога, включая снимки из `screens/`.
2. Первым сообщением отправить содержимое `01-brief.md` целиком. Поле «What do you want designed?» ограничено 400 символами — бриф туда не помещается, он идёт текстом сообщения.
3. Ответы на вводную форму взять из `06-answers.md`.

## Ограничение среды и принятое решение

Среда оформления не создаёт растровые изображения: доступны разметка, схемы и векторная графика, написанная кодом. Художественная иллюстрация в ней не получится.

Решение заказчика: идём плоской векторной графикой. Она переводится в Android Vector Drawable, держит послойную схему и не увеличивает размер сборки. Пример структуры — `07-pet-vector-demo.html`, требования к выдаче — `05-pet-system.md`.

## Перенос результата в приложение

Интерфейс написан на Jetpack Compose, поэтому HTML-превью из среды оформления не подключается напрямую. Переносятся:

- значения цвета, размеров и раскладки — в `app/src/main/kotlin/ru/onefortwo/finny/ui/theme/Theme.kt` и `app/src/main/kotlin/ru/onefortwo/finny/ui/common/Components.kt`;
- векторная графика — из SVG в Android Vector Drawable, в `app/src/main/res/drawable`.

Перенос выполняется вручную: автоматической синхронизации с репозиторием нет.
