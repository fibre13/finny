# Дизайн-система «Питомец Финни»

Визуальный язык Android-приложения по финансовой грамотности для детей 7–11 лет. Приложение написано на Kotlin и Jetpack Compose; эта система — читаемое зеркало его токенов, а не исходник сборки. Значения совпадают с `ui/theme/Theme.kt` и `ui/common/Components.kt` в репозитории проекта.

## Как этим пользоваться

- Подключать единственный лист стилей: `<link rel="stylesheet" href="styles.css">` (путь поправить под вложенность). Все цвета, размеры, радиусы и отступы брать переменными: `var(--c-*)`, `var(--t-*)`, `var(--s-*)`, `var(--r-*)`.
- Не вписывать значения прямо в разметку. Расхождение с приложением обнаружится только при переносе в Compose, когда переделывать дороже.
- Собирать из классов ниже, а не заводить параллельные. Страницы компонентов — обычный HTML, разметку видно исходником.
- Тёмная пара включается атрибутом `data-theme="dark"` на корневом элементе. В приложении она следует системной настройке.

## Жёсткие ограничения

Заданы техническим заданием конкурса и проверены на устройстве. Нарушать нельзя даже ради внешнего вида.

| Ограничение | Значение |
|---|---|
| Платформа | Android 8.0 и выше |
| Ориентация | Портретная обязательна, ширина от 360 dp; альбомная и планшет поддержаны |
| Ширина содержимого | Не более 640 dp, на широких экранах центрируется |
| Минимальный интерактивный элемент | 48 × 48 dp |
| Основной текст | Не ниже 16 sp; раскладка выдерживает увеличение шрифта до 1,5× |
| Контраст текста к фону | Не ниже 4,5:1 |
| Контур интерактивного элемента | Не ниже 3:1 по WCAG 1.4.11 |
| Шрифт | Системный. Веб-шрифты не подключаются: приложение работает без сети |
| Движение и звук | Отсутствуют; только системные переходы |

**Состояние всегда передаётся текстом и пиктограммой, цвет только дополняет.** Это требование, а не стилистика: недоступное украшение подписано «— не куплено», выбранное — «— надето», неактивная кнопка сопровождается пояснением причины рядом. Убирать подпись, оставив один цвет, нельзя.

**Ошибка не наказывается.** Неверный ответ на задание всё равно приносит монеты и разбор, тон нейтральный. Красным помечаются сбои ввода, а не решения ребёнка.

**Персональные данные не запрашиваются.** Единственный вопрос о ребёнке — класс, и только чтобы подобрать сложность заданий.

## Цвет

Светлая пара — основная. Роли и значения на странице `foundations/color.html`.

Три цвета направлений плана бюджета — «Нужное» `--c-needs`, «Хочу» `--c-wants`, «Копилка» `--c-savings` — не являются ролями интерфейса: это обозначения учебных категорий. В коде они вынесены отдельно от схемы Material.

`--c-outline` применяется к контурам интерактивных элементов и рассчитан на порог 3:1. `--c-outline-variant` — служебная линейка и разделитель, к нему порог не применяется. Менять их местами нельзя.

## Типографика

Системный Roboto. Размеры на странице `foundations/type.html`. Основной текст 16 sp — нижняя граница, мельче нельзя. Полужирное начертание применяется точечно: заголовок экрана, заголовок карточки, надпись на кнопке, числовое значение показателя.

## Направление 1b «Аппликация»

Выбранное оформление: бумажная вырезка. Контур `--stroke-1b` 2,5 dp цветом `--c-ink`, сплошное смещение `--offset-1b` вместо размытой тени, при нажатии тень убирается и элемент смещается. Фон `--c-paper` с точечным узором.

Оформление 1b накладывается поверх ролей цвета, а не заменяет их.

## Компоненты

| Класс | Что это | Страница |
|---|---|---|
| `.btn` с `.btn-primary`, `.btn-secondary`, `.is-selected`, `[disabled]` | Действия. Основное — заливка `--c-primary` | components/buttons.html |
| `.card` с `.card-title` | Карточка раздела | components/cards.html |
| `.feedback` с `.problem` | Сообщение о произошедшем; проблемное отличается словом «Внимание» | components/cards.html |
| `.kv` | Строка «подпись — значение» | components/cards.html |
| `.stat` + `.bar` | Показатель питомца: пиктограмма, метка, число, полоса | components/stats.html |
| `.swatch` | Плитка окраса рядом с кнопкой выбора | components/buttons.html |
| — | Пиктограммы: уровень показателя, направления, итог задания, монета | components/pictograms.html |

## Пиктограммы

Сетка 24 × 24, координаты те же, что в приложении. Толщина обводки берётся токеном `--stroke-pictogram` и от размера не зависит: в SVG это `vector-effect: non-scaling-stroke`, в Compose — перевод в единицы сетки обратным масштабом при отрисовке. Страница `components/pictograms.html`.

Уровень показателя выводится в 28 dp, направления плана — в 48 dp: миска, звезда и копилка состоят из нескольких частей и при 28 dp сливаются в пятно.

## Фигура питомца

Один компонент из четырёх слоёв вместо 81 изображения: силуэт (вид × стадия), заливка окраса, украшение, выражение по паре показателей. Система координат 200 × 200, общая точка привязки украшения у шеи. Страница `components/pet.html`.

Только заливки, обводки и группы с преобразованиями. Фильтры, маски, режимы наложения и растровые вставки не применять: они не переносятся в Android Vector Drawable.

## Чего не делать

- Не заводить размеры текста ниже 16 px для основного текста.
- Не передавать состояние одним цветом.
- Не подключать веб-шрифты и внешние изображения.
- Не добавлять анимации и переходы.
- Не менять тексты интерфейса: они проверены на устройстве и зафиксированы в `docs/design/04-screens.md` репозитория.

## Файлы

- `styles.css` — единственный лист стилей: переменные и слой компонентов.
- `theme.json` — машиночитаемая запись параметров.
- `foundations/color.html` — роли цвета, обе пары, контраст.
- `foundations/type.html` — размеры и начертания.
- `foundations/layout.html` — отступы, радиусы, минимальные размеры.
- `components/buttons.html` — кнопки и выбор в состояниях.
- `components/cards.html` — карточки раздела и сообщения.
- `components/stats.html` — показатели и полосы.
- `components/pet.html` — послойная фигура питомца.
- `components/pictograms.html` — пиктограммы на сетке 24 × 24.
- `components/background.html` — фон главного экрана слоями.
- `components/house.html` — дом питомца.
