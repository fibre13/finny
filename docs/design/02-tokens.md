# Действующие токены

Источник значений: `app/src/main/kotlin/ru/onefortwo/finny/ui/theme/Theme.kt` и `app/src/main/kotlin/ru/onefortwo/finny/ui/common/Components.kt`.

## Цвет

Схема Material 3, только светлая. Тёмная схема не определена — её требуется спроектировать.

| Роль Material 3 | Значение | Где применяется |
|---|---|---|
| `primary` | `#3D7C47` | Основная кнопка, выбранный вариант в списках |
| `onPrimary` | `#FFFFFF` | Текст на основной кнопке |
| `secondary` | `#F2B705` | Фон карточки сообщения о проблеме |
| `onSecondary` | `#2B2B2B` | Текст на этой карточке |
| `background` | `#FFFBF2` | Фон экрана |
| `onBackground` | `#2B2B2B` | Основной текст |
| `surface` | `#FFFFFF` | Карточки разделов и обычных сообщений |
| `onSurface` | `#2B2B2B` | Текст в карточках |
| `error` | `#B3261E` | Сообщения об ошибке ввода |

Цвета окраса питомца заданы отдельно в контенте (`content/src/main/assets/pet_parts.json`) и в схему Material не входят:

| Окрас | Значение |
|---|---|
| Рыжий | `#E8913A` |
| Серый | `#9AA5B1` |
| Белый | `#EDE4D6` |

## Типографика

Системный шрифт. Собственный шрифт не подключён.

| Стиль Material 3 | Размер / межстрочный интервал | Где применяется |
|---|---|---|
| `titleLarge` | 24 / 32 sp | Заголовок экрана, имя питомца, подпись вида на фигуре |
| `bodyLarge` | 18 / 26 sp | Крупный текст |
| `labelLarge` | 18 / 24 sp | Текст кнопок |
| `bodyMedium` | 16 / 24 sp | Основной текст, подписи, значения |

Начертание: обычное; полужирное применяется точечно — имя питомца, числовое значение показателя, заголовок карточки сообщения.

## Размеры и раскладка

| Параметр | Значение |
|---|---|
| Минимальная высота интерактивного элемента | 48 dp |
| Максимальная ширина содержимого | 640 dp, по центру |
| Горизонтальный отступ содержимого | 16 dp |
| Нижний отступ содержимого | 24 dp |
| Размер фигуры питомца | 140 dp |
| Скругление фигуры питомца | 24 dp |
| Скругление полосы прогресса | 6 dp |
| Внутренний отступ карточки | 16 dp |
| Шаг вертикальных отступов | 4 / 8 / 12 / 16 / 24 dp |

Каждый экран целиком прокручивается по вертикали: содержимое помещено в общий контейнер с прокруткой, отдельных прокручиваемых областей внутри нет.

## Чего в токенах нет и что требуется задать

- Тёмная пара для каждой роли цвета.
- Отдельный набор для режима слабого зрения: усиленный контраст и увеличенные элементы.
- Цвета состояний питомца («Голодный», «Скучает» и прочие) — сейчас передаются только текстом и символом.
- Цветовое разделение направлений «Нужное», «Хочу», «Копилка» — сейчас отсутствует, различаются только подписями.
- Тень и граница карточек — используются значения библиотеки по умолчанию.
