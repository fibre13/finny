# Бриф

## Продукт

«Питомец Финни» — Android-приложение по финансовой грамотности для детей 7–11 лет (1–4 класс). Разрабатывается для конкурса Департамента финансов города Москвы.

Игровой цикл: ребёнок получает игровые монеты на игровой день, распределяет их между направлениями «Нужное», «Хочу» и «Копилка», покупает необходимое питомцу, копит на выбранную цель и выполняет короткие задания по трём темам. Состояние питомца зависит от принятых решений. Ошибка не наказывается: приложение объясняет, что произошло, и предлагает следующий шаг.

Прототип функционально завершён и проверен на устройстве: 13 экранов, 147 автотестов, подписанная релизная сборка. Вся графика — временные цветные прямоугольники с подписью вида питомца.

## Задача

Собрать визуальную систему: токены, состояния компонентов, изображение питомца, пиктограммы, фон.

Не менять: структуру и порядок экранов, тексты интерфейса, правила экономики. Они проверены на устройстве и зафиксированы в документации проекта.

## Обязательные ограничения

| Ограничение | Значение |
|---|---|
| Платформа | Android 8.0 и выше |
| Ориентация | Портретная обязательна, ширина от 360 dp; альбомная и планшет поддержаны |
| Ширина содержимого | Не более 640 dp, на широких экранах центрируется |
| Минимальный интерактивный элемент | 48 × 48 dp |
| Основной текст | Не менее 16 sp; раскладка выдерживает системное увеличение шрифта до 1,5× |
| Контраст текста к фону | Не менее 4,5:1 (текущий минимум по расчёту — 4,87:1) |
| Передача состояния | Текст и пиктограмма обязательны, цвет только дополняет |
| Содержимое | Без рекламы, платных покупок, персональных данных и обращений к сети |
| Движение и звук | В прототипе отсутствуют; используются только системные переходы |
| Работа без сети | Полностью автономное приложение |

Отдельное требование интерфейса: ограничение экранного времени 20 минут в сутки с предупреждением за 5 минут, и не более одного игрового дня за календарные сутки. Оба ограничения показываются блоками на главном экране и управляются из раздела для взрослого.

## Приоритет задач

1. **Токены.** Палитра парами «светлая / тёмная» и шкала размеров. От них зависит всё остальное. Тёмная тема и режим для слабого зрения находятся в плане развития, поэтому пары задаются сразу, иначе токены придётся переопределять повторно.
2. **Питомец.** Плоская векторная графика — стиль выбран, к обсуждению не возвращаемся. Послойная система: 3 вида × 3 окраса × 3 украшения × 3 стадии роста, поверх — состояния по двум показателям. Требования к выдаче и пример структуры — в `05-pet-system.md`.
3. **Три ключевых экрана** в новом оформлении: Главный, План бюджета, Задание.
4. **Остальные экраны**, пиктограммы направлений и показателей, фон главного экрана и дом питомца.

## Ожидаемый результат

- Токены цвета и размеров, светлая и тёмная пары.
- Компоненты из `03-components.md` в состояниях: обычное, нажатое, неактивное, выбранное.
- Спецификация фигуры питомца по слоям.
- Три ключевых экрана.
