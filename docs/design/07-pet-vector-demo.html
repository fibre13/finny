Векторный питомец: что реально получается кодом

Набросок сделан вручную теми же средствами (SVG-примитивы, переменные цвета), какими это делает код-модель. Показывает потолок качества, а не конкретный будущий результат.

Три вида × три окраса

Один силуэт на вид. Окрас — подстановка цвета, не отдельный файл.

Украшения — отдельный слой поверх

Точка привязки общая, поэтому бантик не перерисовывается под каждый вид.

Выражение по показателям

Дополняет текстовую метку «Голодный / В порядке / Довольный», не заменяет её.

Как это выглядит в приложении

Слева — сейчас, справа — тот же блок с векторной фигурой. Размер фигуры 140 dp в обоих случаях.
