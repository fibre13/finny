# Система изображения питомца

## Что есть сейчас

Квадрат 140 dp со скруглением 24 dp, залитый цветом окраса, с названием вида по центру. Под ним имя питомца и строка «Стадия, украшение». Реализация — `PetFigure` в `app/src/main/kotlin/ru/onefortwo/finny/ui/common/Components.kt`.

## Измерения

| Измерение | Варианты | Источник |
|---|---|---|
| Вид | Котёнок, Щенок, Крольчонок | `pet_parts.json`, поле `species` |
| Окрас | Рыжий `#E8913A`, Серый `#9AA5B1`, Белый `#EDE4D6` | `pet_parts.json`, поле `colors` |
| Украшение | Без украшения, Бантик, Шарфик | `pet_parts.json`, поле `accessories` |
| Стадия роста | Малыш, Подросток, Взрослый | `GrowthStage` в модуле `core-economy` |
| Забота | Голодный (0–33), В порядке (34–66), Довольный (67–100) | `core-economy` |
| Радость | Скучает (0–33), Спокойный (34–66), Весёлый (67–100) | `core-economy` |

Вид, окрас, украшение и стадия дают 81 комбинацию. Состояния по двум показателям умножают это число ещё на девять, если делать выражения отдельными изображениями.

## Требование

Нужна послойная схема, а не набор готовых изображений:

1. **Силуэт** — определяется парой «вид × стадия»: девять силуэтов. Стадия меняет пропорции, а не персонажа: «Малыш» крупнее голова, «Взрослый» вытянутее.
2. **Заливка окраса** — один слой, цвет подставляется из контента. Оттенки для затенения выводятся из основного цвета, а не задаются отдельно для каждого окраса.
3. **Накладка украшения** — отдельный слой поверх силуэта: два варианта плюс пустой. Точка привязки должна быть общей для всех девяти силуэтов, иначе украшение придётся рисовать под каждую комбинацию.
4. **Выражение** — определяется парой показателей: отдельный слой глаз и рта, три-четыре варианта. Низкая «Забота» и низкая «Радость» дают разные выражения.

Комбинаторика при такой схеме: 9 силуэтов + 1 заливка + 3 украшения + 4 выражения вместо 81 изображения.

## Ограничения

- **Только вектор.** Подписанный APK сейчас 8 990 198 байт. Растровый набор под все комбинации и под разные плотности экрана существенно его увеличит.
- **Формат переноса.** SVG, из которого выполняется перевод в Android Vector Drawable. Ограничения этого формата: заливки и обводки, линейные и радиальные градиенты, группы с преобразованиями. Фильтры, маски, режимы наложения и растровые вставки не поддерживаются.
- **Читаемость при 140 dp.** Фигура выводится в этом размере, мелкие детали в нём не различаются.
- **Состояние дублируется текстом.** Выражение питомца только дополняет текстовую метку показателя, замещать её не должно.
- **Без анимации.** В прототипе анимаций нет.

## Принятое решение

Стиль — **плоская векторная графика**, собираемая кодом. Решение принято заказчиком; вариант с размеченными заглушками под работу иллюстратора не рассматривается.

Пример достижимого уровня — `07-pet-vector-demo.html`. Это ручной набросок теми же средствами: он показывает структуру слоёв и точки привязки, а не целевой стиль. Стиль в рамках плоского вектора предстоит выбрать из предложенных направлений.

## Требования к выдаче

Чтобы результат переносился в приложение без переделки:

| Требование | Значение |
|---|---|
| Формат | SVG, по одному `<g>` на слой |
| Система координат | Единый `viewBox` для всех слоёв, чтобы накладки совпадали без подгонки |
| Идентификаторы | Осмысленные и единообразные: `sil-cat-baby`, `acc-bow`, `exp-happy` |
| Заливка силуэта | Один именованный цвет или `currentColor` — окрас подставляется, а не зашивается |
| Затенение | Полупрозрачная заливка поверх (`#000` или `#fff` с прозрачностью) |
| Допустимо | Пути, окружности, эллипсы, группы с преобразованиями, обводки, линейные и радиальные градиенты |
| Недопустимо | Фильтры, маски, режимы наложения, растровые вставки |
| Читаемость | Проверять на 140 dp — это фактический размер фигуры в приложении |

## Прочая графика

| Объект | Назначение |
|---|---|
| Пиктограммы направлений | «Нужное», «Хочу», «Копилка» — сейчас различаются только подписями |
| Пиктограммы уровня показателя | Замена символов `!`, `~`, `+` |
| Фон главного экрана | Сейчас однотонный `#FFFBF2` |
| Дом питомца | Отсутствует; упоминается в плане развития |
| Иконка приложения | Рабочая версия есть, возможна переработка |
