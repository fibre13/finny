# Набор тест-кейсов

Набор ручных проверок прототипа «Питомец Финни» с привязкой к требованиям технического задания. Соответствует пункту ТЗ 5.10. Кейсы описывают версию 0.7.0 (versionCode 16). Статус каждого кейса отражает фактический результат: прогон на эмуляторе Android 8.0 по журналу `docs/03-проверка-на-устройстве.md`, автоматизированный тест по `docs/02-правила-экономики-и-тесты.md` и отчётам JUnit, либо отметка о том, что проверка не выполнялась или не записана.

Прогон версии 0.7.0 на эмуляторе записан в docs/03, раздел «Версия 0.7.0: сборка, автотесты и раскладка двора на разных экранах»: раскладка двора на экранах 360 × 800 и 360 × 640 dp и на планшете 1280 × 800 dp в обеих ориентациях. Там же, в разделе «Незавершённые проверки», п. 2, указано, что на эмуляторе 360 × 800 dp пройдены шаги первого дня по подсказкам и переход в новые календарные сутки, а журнал этого прохода с точными выводами не сохранялся. Статус «Эмулятор» у кейсов первого дня и нового дня опирается на эту запись.

Автоматизированные тесты: 264, из них в модуле `app` — 113, `content` — 85, `core-economy` — 66; отказов и ошибок нет (отчёты `*/build/test-results`, 28.09.2026).

Обозначения статуса:

| Статус | Значение |
|---|---|
| Эмулятор | Выполнено вручную на эмуляторе Android 8.0, API 26 |
| Автотест | Покрыто автоматизированным тестом, выполняющимся на JVM |
| Расчёт | Проверено вычислением по исходным данным или по коду |
| Физическое устройство | Выполнено на физическом устройстве |
| Нет записи | Автотеста нет, ручная проверка в журнале docs/03 не записана |
| Не выполнено | Проверка не проводилась, причина указана |

Предусловие для всех кейсов, если не указано иное: приложение установлено, профиль не создан, движения питомца включены.
