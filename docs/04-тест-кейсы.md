# Набор тест-кейсов

Набор ручных проверок прототипа «Питомец Финни» с привязкой к требованиям технического задания. Соответствует пункту ТЗ 5.10. Статус каждого кейса отражает фактический результат: прогон на эмуляторе Android 8.0 по журналу `docs/03-проверка-на-устройстве.md`, автоматизированный тест по `docs/02-правила-экономики-и-тесты.md`, либо отметка о невыполненной проверке.

Обозначения статуса:

| Статус | Значение |
|---|---|
| Эмулятор | Выполнено вручную на эмуляторе Android 8.0, API 26 |
| Автотест | Покрыто автоматизированным тестом, выполняющимся на JVM |
| Расчёт | Проверено вычислением по исходным данным |
| Физическое устройство | Выполнено пользователем на планшете |
| Не выполнено | Проверка не проводилась, причина указана |

Предусловие для всех кейсов, если не указано иное: приложение установлено, профиль не создан.
