# Документация проекта «Питомец Финни»

Порядок чтения для эксперта конкурса: **09 → 07 → 02 → 03**. Сверка показывает, что и где реализовано; пакет сдачи собирает материалы по пунктам задания; правила экономики объясняют расчёты; журнал проверки показывает поведение на устройстве.
