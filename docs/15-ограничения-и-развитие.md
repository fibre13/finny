# Известные ограничения и план развития

Документ выполняет пункт 5.11 технического задания: сводный перечень известных ограничений прототипа версии 0.7.0 и план дальнейшего развития. Подробности проверки — в docs/03 и docs/10, решения — в docs/01.

## 1. Известные ограничения

### Проверка

| № | Ограничение | Где зафиксировано |
|---|---|---|
| 1 | Проверка с детьми целевого возраста и независимая экспертная проверка (педагог, специалист по финансовой грамотности, UX) не проводились; приложение проверяла команда проекта | docs/10, раздел 6 |
| 2 | Проверены два физических устройства — Xiaomi MI 5 с Android 8.0 и OPPO CPH2711 с Android 16 — и эмуляторы Android 8.0; версии Android 9–15 не проверялись | docs/03, docs/10 |
| 3 | Автотестов переходов схемы базы (`MigrationTestHelper`) нет; переходы проверяются установкой новой сборки поверх прежней. Исправленный переход 7 → 8 на устройстве с базой версии 7 не проверен | docs/01, раздел 14; docs/03 |
| 4 | Контраст пар цветов пиксельной графики двора (надписи на табличках, доске, кнопке «Закончить день») не рассчитан; рассчитан только контраст цветов темы | docs/09, пункт 3.6 |
| 5 | Первый запуск сразу после установки обновления на Xiaomi MI 5 занял 32,8 с (разовая подготовка кода устройством); причина отдельно не исследовалась | docs/10, раздел 5 |

### Продукт

| № | Ограничение | Причина или решение |
|---|---|---|
| 6 | Один профиль на устройстве | Хранение рассчитано на один профиль; несколько профилей — в плане развития |
| 7 | Уровень заданий меняется только пересозданием профиля | Уровень выбирается при знакомстве |
| 8 | Тёмная тема и чёрно-белый режим выключены | Под текущее оформление не подготовлены; хранилище настроек сохранено |
| 9 | Звуков нет | Осознанное решение: важная информация передаётся текстом и изображением |
| 10 | Экранное время — предупреждение, а не блокировка; счётчик хранится в профиле и при сбросе профиля переносится в новый, пока приложение открыто | Начатое действие не обрывается (docs/01, раздел 13) |
| 11 | Имя питомца подставляется в тексты без склонения | Тексты построены так, что имя стоит в именительном падеже; задание восстановления называется «Помоги своему питомцу» |
| 12 | На экранах высотой около 800 dp облачко подсказки первого шага закрывает неактивную кнопку «Закончить день» | Причина недоступности видна под кнопкой; на этом шаге кнопка не нужна |
| 13 | Учебный контент обновляется только новой сборкой приложения | Серверной части нет (ТЗ 3.2) |
| 14 | Темы Единой рамки компетенций «Иностранная валюта», «Предпринимательство», «Страхование», «Права и обязанности пользователей финансовых услуг», «Финансовые взаимоотношения с государством» не рассматриваются | Вне шести приоритетных компетенций раздела 1 ТЗ (docs/12) |
| 15 | Обоснование соответствия требованиям 436-ФЗ не оформлено | Вынесено в вопросы к организатору (docs/09) |

## 2. План развития

| Направление | Содержание | Порядок |
|---|---|---|
| Публикация | Публикация в RuStore по подготовленной карточке (docs/06) | После конкурсной экспертизы |
| Проверка | Проверка с детьми 7–11 лет при согласии законных представителей; экспертная проверка содержания; устройства с Android 10–14 | До публикации |
| Надёжность | Автотесты переходов схемы на `MigrationTestHelper`; расчёт контраста пиксельной графики | До публикации |
| Несколько профилей | Выбор профиля при запуске, вход по картиночному коду | Следующая версия |
| Смена сложности | Изменение уровня заданий в разделе для взрослого без пересоздания профиля | Следующая версия |
| Контент | Новые темы Единой рамки: иностранная валюта, права потребителя, налоги как источник общественных благ; новые задания добавляются записью в `tasks.json` | По мере готовности |
| Оформление | Тёмная тема и чёрно-белый режим с усиленной обводкой | После проверки с детьми |
| Участие взрослого | Ручное поощрение ребёнка из раздела для взрослого | После проверки с семьями |
