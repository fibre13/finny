# Отчёт о проверке решения

Отчёт составлен по составу, названному организатором в ответах на вопросы: кто проверял, какие задания проходил, что получилось, что исправлено. Отдельно отмечено, что проверка была самопроверкой.

## 1. Кто проверял

**Самопроверка.** Приложение проверял разработчик проекта — он же единственный участник команды. Независимой проверки с педагогом, специалистом по финансовой грамотности или UX не проводилось, проверки с детьми — тоже. Это существенное ограничение отчёта, и оно названо здесь прямо, а не смягчается формулировками.

Проверка с детьми требует согласия законных представителей; организатор допускает вместо неё экспертную проверку. Ни та, ни другая на момент промежуточной сдачи не выполнены.

## 2. Условия

| Что | Значение |
|---|---|
| Устройство | Xiaomi MI 5 (`gemini`) |
| Версия Android | 8.0.0, уровень API 26 |
| Оперативная память | 3 ГБ номинально (`MemTotal` 2 775 024 кБ) |
| Сборка | подписанный релиз, versionName 0.3.1 и 0.3.2 |
| Дополнительно | эмулятор `finny_api26`, Android 8.0 (API 26) |
| Даты | 16–17 сентября 2026 |

Установка выполнялась командой `adb install -r` без среды разработки.

## 3. Что проходили

Полный сквозной сценарий Приложения А, все двенадцать шагов: знакомство, создание профиля, стартовый бюджет, план на день, задание с верным и с ошибочным ответом, обязательная и необязательная покупки, попытка покупки при нехватке монет, выбор цели и пополнение копилки, завершение дня с итогами, перезапуск приложения, раздел для взрослого со сбросом профиля.

Дополнительно: пять игровых периодов подряд в демонстрационном режиме до третьей стадии развития питомца; тёмная пара и чёрно-белый режим на всех экранах; обновление приложения поверх работающего профиля.

Проходились задания всех четырёх типов: распределение суммы ползунками, отметка в списке, ввод числа, выбор решения с последствиями.

## 4. Что нашли и что исправили

### Первый проход (на версии 0.2.x)

| Что замечено | Подтвердилось | Что сделано |
|---|---|---|
| День не завершался после утверждения плана | Да | День считается прожитым, если было решение: покупка **или** отложенные монеты. Раньше требовалась именно покупка, и ребёнок, отложивший всё в копилку, не мог закончить день |
| На главном экране видна только последняя покупка | Да | Добавлена карточка «Сегодня куплено» со списком и суммой |
| Задания повторяются слово в слово, за неделю заканчиваются | Да | Девять заданий из одиннадцати берут числа заново при каждом открытии |
| Одинаковые ли задания на разных уровнях | Нет, наборы разные | Различие сведено в таблицу в проектных решениях: названия совпадают намеренно, содержание различается |
| Голова наезжает на туловище | Да | Перекрытие уменьшено с 16 до 8 |

### Третий проход: замечания тестировщика (24.09)

Замечания переданы 24.09.2026. Сборка, режим и устройство, на которых они получены, в замечаниях не указаны. Каждое замечание разобрано по коду и техническому заданию. На прежней сборке 0.4.0 воспроизведены два дефекта — потеря сумм плана и смена чисел при повороте; расхождение суммы на карточке результата подтверждено автотестом, который на прежнем коде падает; остальные выявлены разбором кода. Все исправления проверены на исправленной сборке — журнал в `docs/03-проверка-на-устройстве.md`, раздел «Проверка исправлений по отзыву тестировщика».

| Что замечено | Подтвердилось | Что сделано |
|---|---|---|
| Чтобы перейти к новому дню, план заполняют дважды | Да | План с копилкой без выбранной цели отклонялся, экран закрывался, суммы пропадали. Экран закрывается только принятым планом; на карточке «Копилка» — подсказка и кнопка «Выбрать цель», суммы при переходе сохраняются |
| Новый день, а задания подписаны «пройти ещё раз», хотя не пройдены | Да | В пройденные попадал любой ответ, в том числе ошибочный, а подпись говорила «Выполнено». Подписи заменены: «Ещё не решал», «Уже решал», «Решить ещё раз»; новые числа обещаются только заданиям, где они есть |
| Найдено при разборе: при повторе карточка результата называла полную награду, а начислялась половина | Да | Карточка называет фактически начисленную сумму |
| Найдено при разборе: при повороте экрана числа задания менялись, а введённый ответ оставался | Да | Сохраняется зерно случайных чисел, условие восстанавливается из него |

| Найдено при разборе: кнопка «Помоги Финни» открывала общий список заданий | Да | Кнопка открывает само задание |
