# Бриф на визуальный дизайн

Исходные данные для проработки оформления в среде визуального дизайна. Значения взяты из кода и контента репозитория: палитра и типографика — `app/src/main/kotlin/ru/onefortwo/finny/ui/theme/Theme.kt`, размеры и компоненты — `app/src/main/kotlin/ru/onefortwo/finny/ui/common/Components.kt`, состав внешности питомца — `content/src/main/assets/pet_parts.json`, ограничения — техническое задание и журнал проверки `docs/03-проверка-на-устройстве.md`.

## 1. Продукт

«Питомец Финни» — Android-приложение по финансовой грамотности для детей 7–11 лет (1–4 класс). Ребёнок получает игровые монеты на игровой день, распределяет их между направлениями «Нужное», «Хочу» и «Копилка», покупает необходимое питомцу, копит на цель и выполняет короткие задания. Прототип функционально завершён; вся графика — временные цветные прямоугольники с подписью.

Задача дизайна: собрать визуальную систему — питомец, фон, иконки, токены цвета и размеров, состояния компонентов. Структура экранов, тексты интерфейса и правила экономики зафиксированы и проверены на устройстве, изменению в рамках этой задачи не подлежат.

## 2. Обязательные ограничения

| Ограничение | Значение |
|---|---|
| Платформа | Android 8.0 и выше |
| Ориентация | Портретная обязательна, ширина от 360 dp; альбомная и планшет поддержаны |
| Ширина содержимого | Не более 640 dp, на широких экранах центрируется |
| Минимальный интерактивный элемент | 48 × 48 dp |
| Основной текст | Не менее 16 sp; раскладка выдерживает системное увеличение шрифта до 1,5× |
| Контраст текста к фону | Не менее 4,5:1 (текущий минимум по расчёту — 4,87:1) |
| Передача состояния | Текст и пиктограмма обязательны, цвет только дополняет |
| Содержимое | Без рекламы, платных покупок, персональных данных и обращений к сети |
| Движение и звук | В прототипе отсутствуют; собственных анимаций нет |

## 4. Компоненты в коде

Для каждого требуются визуальные состояния: обычное, нажатое, неактивное, выбранное.

| Компонент | Назначение |
|---|---|
| `ScreenScaffold` | Каркас экрана: заголовок и кнопка «Назад» в одном месте на всех экранах |
| `PrimaryButton` | Основное действие экрана |
| `SecondaryButton` | Второстепенное действие |
| `SectionCard` | Карточка раздела с заголовком |
| `FeedbackCard` | Сообщение о произошедшем: обычное, со строкой «Что дальше», проблемное |
| `LabeledValue` | Пара «подпись — значение» |
| `StatBar` | Показатель питомца: число, текстовая метка, пиктограмма, шкала |
| `ProgressBar` | Прогресс накопления к цели |
| `PetFigure` | Фигура питомца, имя, стадия и украшение |

Тринадцать экранов: Знакомство, Создание питомца, Главный, План бюджета, Задания, Задание, Покупки, Копилка и цель, Итоги дня, Мой прогресс, Словарик, Раздел для взрослого, Гардероб.

Снимки текущего состояния — `docs/screenshots/`.

## 6. Питомец: основная задача

Требуется система слоёв, а не набор готовых изображений.

| Измерение | Варианты |
|---|---|
| Вид | Котёнок, Щенок, Крольчонок |
| Окрас | Рыжий `#E8913A`, Серый `#9AA5B1`, Белый `#EDE4D6` |
| Украшение | Без украшения, Бантик, Шарфик |
| Стадия роста | Малыш, Подросток, Взрослый |
| Забота | Голодный, В порядке, Довольный |
| Радость | Скучает, Спокойный, Весёлый |

Комбинаций вида, окраса, украшения и стадии — 81, к ним добавляются состояния по двум показателям. Отсюда требование: силуэт вида и вариант стадии, отдельная заливка окраса, отдельная накладка украшения, отдельное выражение по состоянию. Векторный формат обязателен: текущий размер подписанного APK — 8 990 198 байт, и растровый набор такого объёма его существенно увеличит.

## 7. Приоритет остальных задач

1. Пиктограммы направлений: «Нужное», «Хочу», «Копилка».
2. Пиктограммы показателей: сейчас используются символы `!`, `~`, `+`.
3. Фон главного экрана и дом питомца.
4. Иконка приложения: рабочая версия есть (`docs/rustore/icon-512.png`), возможна переработка.

## 8. Отложено, но влияет на решения сейчас

Тёмная тема и режим для слабого зрения находятся в плане развития (`docs/01-проектные-решения.md`, раздел 15). Палитру целесообразно задавать сразу парами «светлая / тёмная», иначе токены придётся переопределять повторно.

## 9. Ожидаемый результат

- Токены цвета и размеров, светлая и тёмная пары.
- Компоненты из раздела 4 в перечисленных состояниях.
- Спецификация фигуры питомца по слоям.
- Три ключевых экрана в новом оформлении: Главный, План бюджета, Задание.

## 10. Порядок работы

1. Токены: палитра парами и шкала размеров. От них зависит всё остальное.
2. Фигура питомца как система слоёв — наиболее объёмная часть из-за числа комбинаций.
3. Три ключевых экрана на новых токенах и новой фигуре.
4. Остальные экраны, пиктограммы направлений и показателей, фон.

## 11. Перенос результата в приложение

Среда оформления выдаёт систему в виде HTML-превью. Интерфейс приложения написан на Jetpack Compose, поэтому HTML не подключается напрямую: значения цвета, размеров и раскладки переносятся в `Theme.kt` и `Components.kt` вручную, графика питомца и пиктограммы — в формате SVG с последующим переводом в Android Vector Drawable.
