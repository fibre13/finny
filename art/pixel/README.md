# Пиксельная графика «Питомец Финни»

Пиксельный мир питомца: фигуры трёх видов на трёх стадиях, выражения мордочки, украшения, сцена главного экрана, иллюстрации целей, частицы и описание анимации данными. Интерфейс приложения остаётся плоским; пиксельная графика показывается только внутри рамки-окна.

Исходники — текстовые спрайты в `src/`. Скрипт `tools/build.py` проверяет их и собирает `build/pixel_art.json` и страницу просмотра `preview/index.html`.

## Сборка

Команда из корня репозитория (Python 3, только стандартная библиотека):

```
python art/pixel/tools/build.py
```

Результат:

- `art/pixel/build/pixel_art.json` — палитра, спрайты, якоря, анимация (не больше 150 КБ);
- `art/pixel/preview/index.html` — страница просмотра со встроенными данными, открывается из файла.

При ошибке скрипт печатает строки вида `ошибка: <файл>:<строка>: <сообщение>` и завершается с кодом 1; JSON и страница при этом не перезаписываются.

Проверки:

| Проверка | Где |
|---|---|
| Символ вне палитры | любой спрайт |
| Строки разной длины, число строк или ширина не совпадают с заголовком `# ширина высота` | любой спрайт |
| Холст питомца не 48 × 48; фигура касается края холста | `pet/` |
| Нет контура: клетка шерсти `F f G` граничит с прозрачной или с краем | `pet/` |
| Нижняя строка фигуры не 44 (фигура не стоит на базовой линии `y = 45`); тень `z` вне строк 45–46 | `pet/` |
| Иллюстрация цели не 32 × 32; частица больше 7 × 7; слой сцены не 180 × 100 | `goal/`, `fx/`, `scene/` |
| Нет обязательного спрайта законченного вида (6 кадров фигуры, 4 глаз, 5 рта, бантик, шарфик) | вид считается законченным, если есть хотя бы один его спрайт `pet/` |
| Якорь ссылается на несуществующий спрайт; часть по якорю выходит за холст 48 × 48; объект сцены по якорю выходит за сцену | `anchors.json` |
| Реакция ссылается на неизвестную частицу или точку привязки; частица живёт дольше реакции; реакция длиннее 2 с; смещение больше 3 клеток; вспышка длиннее одного такта; моргание чаще трёх раз в секунду; частиц одновременно больше пула | `animation.json` |
| Больше 32 цветов с учётом рамп и тени; основной цвет рампы не равен окрасу из `content/src/main/assets/pet_parts.json` | `palette.txt` |

## Сетки и масштаб

| Что | Логический размер | Как показывается |
|---|---|---|
| Холст питомца | 48 × 48 | Увеличение в целое число раз: `floor(размер_в_px / 48)`, остаток — прозрачные поля по центру. 72 dp на xxhdpi (216 px) — ×4; 96 dp (288 px) — ×6; 140 dp (420 px) — ×8 |
| Сцена | 180 × 100 | Увеличение в целое число раз по ширине окна, остаток — поля цвета неба `A` |
| Питомец в сцене | тот же спрайт 48 × 48 | Точка привязки фигуры ставится в якорь `scene.pet` |
| Иллюстрация цели | 32 × 32 | На экране «Копилка» и в сцене по якорю `scene.goal` |
| Частица | до 7 × 7 | Поверх фигуры или сцены |

Базовая линия фигуры — строка `y = 45`: нижняя строка контура фигуры — 44, тень-пятно `z` — строки 45–46. Фигура стоит по центру по горизонтали, ось симметрии проходит между столбцами 23 и 24.

Высота фигур (строки от верха ушей до низа контура):

| Вид | Малыш | Подросток | Взрослый |
|---|---|---|---|
| `cat` | 27 | 35 | 42 |
| `dog` | 25 | 33 | 41 |
| `rabbit` | 28 | 35 | 42 |

Отрисовка: спрайты кладутся на внеэкранный холст логического размера, затем он переносится на видимый с целым увеличением без сглаживания (в Compose — `FilterQuality.None`, на странице — `imageSmoothingEnabled = false` и `image-rendering: pixelated`). Координаты всегда целые.

## Формат спрайта

```
# 11 8
# pivot 5 3
.KK.....KK.
KnPK...KPPK
...
```

- первая строка — `# ширина высота`;
- вторая (необязательная) — `# pivot x y`: точка привязки в собственных клетках спрайта;
- далее ровно `высота` строк по `ширина` символов палитры.

Точки привязки:

| Спрайт | pivot |
|---|---|
| `pet/*` | `24 45` — середина базовой линии |
| `face/*_eyes_*` (14 × 4) | `7 0` — середина между глазами, верхняя строка |
| `face/*_mouth_*` (6 × 3) | `3 0` — середина, строка сразу под носом |
| `accessory/bow_*` (11 × 8) | `5 3` — узел |
| `accessory/scarf_*_*` | середина ленты, верхняя строка ленты |
| `goal/*` | `16 31` — середина нижней строки |
| `fx/*` | центр |
| `scene/*` | `0 0` |

## Якоря

`src/anchors.json`. Для каждой пары `вид_стадия` — якоря кадров `"0"` и `"1"` в клетках холста 48 × 48 и строка среза дыхания `cut`:

```json
"cat_teen": {
 "cut": 38,
 "0": {"eyes": {"x": 24, "y": 22}, "mouth": {"x": 24, "y": 28}, "bow": {"x": 32, "y": 16},
       "scarf": {"x": 24, "y": 32}, "fx_head": {"x": 24, "y": 7}},
 "1": {"eyes": {"x": 24, "y": 23}, "mouth": {"x": 24, "y": 29}, "bow": {"x": 32, "y": 17},
       "scarf": {"x": 24, "y": 33}, "fx_head": {"x": 24, "y": 8}}
}
```

Точка `pivot` части совмещается с якорем: левый верхний угол части = `якорь − pivot`. Масштаба и поворота у якорей нет.

Кадр `_1` отличается от `_0` тем, что всё выше строки `cut` опущено на одну клетку (строка `cut` исчезает, нижняя часть с лапами остаётся на месте). Поэтому якоря выше `cut` в кадре `"1"` на единицу больше по `y`: лицо и украшения двигаются вместе с головой и шеей.

Якоря сцены (`"scene"`, клетки сцены 180 × 100):

| Якорь | Значение | Что ставится |
|---|---|---|
| `pet` | `132, 90` | pivot фигуры (середина базовой линии) — правая часть сцены |
| `goal` | `84, 89` | pivot иллюстрации цели — средняя часть `x 68…99` |
| `tent` | `8, 37` | левый верхний угол палатки 62 × 52 — левая часть `x 8…69`, `y 37…88` |

## Состав

### Питомец

- `pet/{cat|dog|rabbit}_{baby|teen|adult}_{0|1}.txt` — 18 фигур 48 × 48. Поза — сидя анфас. Нос, щёки, внутренняя часть ушей входят в фигуру; глаза и рот — нет.
- `face/{вид}_eyes_{normal|happy|tired|blink}.txt` — глаза, одинаковые для всех стадий вида.
- `face/{вид}_mouth_{smile|neutral|sad|chew_0|chew_1}.txt` — рот; `chew_0`/`chew_1` — кадры жевания.
- `accessory/bow_{вид}.txt` — бантик у основания правого уха, один на вид.
- `accessory/scarf_{вид}_{стадия}.txt` — шарфик по ширине шеи стадии, со свисающим концом.

Отличительные черты видов: котёнок — треугольные уши с розовой серединой, полоски на лбу, хвост вверх справа; щенок — висячие уши тёмного тона, широкая светлая морда, широкий нос; крольчонок — длинные уши с розовой серединой, крупные задние лапы, хвост-помпон, зубки во рту.

### Сцена

- `scene/sky.txt`, `scene/sky_1.txt` — дневное небо, солнце слева вверху, три облака; во втором кадре облака сдвинуты на клетку вправо.
- `scene/ground.txt` — дальние холмы, луг с травой и цветами, дерево у правого края.
- `scene/tent.txt` — домик-палатка 62 × 52 с флажком; показывается после покупки «Домика-палатки» (`unlocks_scenery: house`).
- `scene/edge_left.txt`, `scene/edge_right.txt` — боковые полосы 40 × 100: продолжение неба, холмов и луга, справа — закругление кроны дерева. Слева и справа от сцены 180 × 100, когда окно шире её; внешние столбцы ровные, и при ещё более широком окне продолжаются без швов.
- `scene/tent_stickers.txt` — наклейки на палатке (звезда, цветок, сердце в белой кайме), слой 62 × 52 поверх `tent` по тому же якорю; показывается после покупки «Наклеек» (`unlocks_scenery: stickers`), если палатка уже есть.

Порядок слоёв: небо, земля, палатка, наклейки, цель, питомец, частицы.

### Цели и частицы

- `goal/{scooter|aquarium|party}.txt` — иллюстрации целей из `goals.json`, 32 × 32.
- `fx/{coin|heart|sparkle|note}_{0..3}.txt`, `fx/crumb_{0..2}.txt` — частицы. Кадры идут от яркого к тусклому: полный размер с бликом, без блика, уменьшенный, наименьший; затем частица исчезает.

## Анимация

`src/animation.json`. Такт — 125 мс (8 в секунду); обновление — фиксированный шаг 60 Гц; отрисовка — по кадру дисплея. Все смещения квантуются до целой клетки.

### Выбор лица и состояния

| Показатели | Глаза | Состояние |
|---|---|---|
| забота низкая | `tired` | `tired` |
| иначе радость высокая | `happy` | `happy` |
| иначе | `normal` | `idle` |

Рот — по радости: высокая → `smile`, средняя → `neutral`, низкая → `sad`.

### Постоянные состояния

| Состояние | Что происходит |
|---|---|
| `idle` | Дыхание: кадры `_0`/`_1` по 4 такта. Моргание: глаза `blink` на 1 такт, следующий раз — через случайные 24–40 тактов |
| `happy` | Как `idle`; раз в 40–64 такта (случайно) прыжок: смещение фигуры `0, −2, −3, −2, 0` клеток по тактам |
| `tired` | Дыхание по 6 тактов, моргание как у `idle`, без прыжков |

Тень `z` при прыжке остаётся на земле; поднимается только фигура с лицом и украшением.

### Реакции на события

| Событие игры | Реакция | Что происходит (16 тактов = 2 с) |
|---|---|---|
| Покупка из категории `needs` | `eat` | Такты 0–7: рот `chew_1`/`chew_0` по 2 такта; такты 1, 3, 5, 7: крошка `crumb` от рта вниз в сторону; такт 9: сердечко `heart` над головой, поднимается |
| Покупка из категории `wants` | `play` | Глаза `happy`; прыжки `0, −2, −3, −2, 0` с тактов 0 и 6; нотки `note` и искры `sparkle` по сторонам головы, поднимаются |
| Пополнение копилки | `save` | Глаза `happy`; три монеты `coin` от груди вверх вправо |
| Переход на новую стадию | `grow` | Такты 0–5: искры `sparkle` в точках контура прежней стадии; такт 6: один светлый кадр силуэта (всё, кроме контура, цветом `c`); такт 7: смена спрайта на новую стадию; такты 8–9: искры по контуру новой стадии |
| Начисление награды за задание | `reward` | Глаза `happy`; три монеты `coin` падают сверху к голове |

Реакция несёт только оформление: смысл события приложение сообщает текстом. После реакции питомец возвращается в постоянное состояние.

Частица задаётся параметрами:

```json
{"at": 9, "fx": "heart", "from": "fx_head", "dx": 0, "dy": 0, "vx": 0, "vy": -0.25, "life": 7}
```

- `at` — такт реакции, на котором частица появляется;
- `from` — точка привязки: якорь (`eyes`, `mouth`, `bow`, `scarf`, `fx_head`) текущего кадра с учётом смещения прыжка, `base` — середина базовой линии, `outline` — точка контура фигуры (`point` из `of` равных долей контура, упорядоченного по углу от центра);
- `dx`, `dy` — сдвиг от точки привязки в клетках;
- `vx`, `vy` — скорость в клетках за такт;
- `life` — время жизни в тактах.

Позиция на такте `age`: `x = floor(x0 + vx · age)`, `y = floor(y0 + vy · age)`. Кадр частицы: `min(n − 1, floor(age · n / life))`, где `n` — число кадров. Пул — 24 частицы, создаётся заранее. На карточке частицы обрезаются холстом 48 × 48.

Ограничения: ничто не мигает чаще трёх раз в секунду; вспышка `grow` — один светлый такт; смещение фигуры — не больше 3 клеток; облака смещаются раз в 32 такта (4 с).

### Режим «анимации выключены»

Включается системной настройкой Android «Удалить анимации» (`Settings.Global.ANIMATOR_DURATION_SCALE == 0`) или переключателем в приложении. В этом режиме: постоянный кадр `_0`, лицо по правилу, без моргания, прыжков и частиц; реакции не показываются; небо — кадр `sky`.

## Выходной JSON

`build/pixel_art.json`:

```
{
 "format": 1,
 "grid": {"pet": [48, 48], "scene": [180, 100], "goal": [32, 32], "baseline": 45},
 "palette": {
  "chars": "KFfGzcblDEegYyORrPpnNAaTtmu",
  "colors": ["#23201A", ...],
  "transparent": -1,
  "fur": {"F": 1, "f": 2, "G": 3},
  "ramps": {"ginger": ["#E8913A", "#B5532F", "#F6BD66"], ...},
  "shadow": {"index": 4, "card": "#D8CFB9", "scene": "#5E8B68"}
 },
 "species": ["cat", "dog", "rabbit"],
 "sprites": [{"id": "cat_adult_0", "kind": "pet", "w": 48, "h": 48, "pivot": [24, 45], "rows": [...]}, ...],
 "anchors": {...},
 "animation": {...}
}
```

Строка спрайта записана либо строкой символов палитры (индекс символа = позиция в `palette.chars`, `.` — прозрачная клетка), либо сериями `[индекс, длина]` с индексом `−1` для прозрачных клеток — что короче. Цвет клетки: `palette.colors[индекс]`; индексы из `palette.fur` заменяются рампой окраса, индекс `palette.shadow.index` — значением тени для фона.

## Страница просмотра

`preview/index.html` открывается из файла, без сети. Разделы:

- все сочетания вид × стадия × окрас × украшение на `#FFFDF8`, ×2;
- все сочетания на `#E7EDDC` в ×1 и ×2 и каждая фигура в ×1, ×2, ×4 рядом;
- 9 сочетаний выражения (забота × радость) для каждого вида;
- живой питомец: выбор вида, стадии, окраса, украшения, заботы, радости, размера показа; кнопки реакций; переключатель «Анимации выключены» (по умолчанию — по системной настройке `prefers-reduced-motion`);
- раскадровка: кадры дыхания `_0`/`_1` каждой фигуры и каждый такт каждой реакции;
- сцена без палатки и цели и с палаткой и каждой из трёх целей, с живым питомцем.

Параметры адреса для снимков: `only=grid,scales,faces,live,strips,scene` — показать разделы; `ticks=N` — выполнить N тактов и остановиться; `react=имя&react_at=T` — запустить реакцию на такте T; `reduced=1`; `species`, `stage`, `color`, `acc`, `care`, `joy`, `size` — настройки питомца; `seed` — начальное значение случайных интервалов; `hideheader=1`.

## Предложения для встраивания

Данные: `build/pixel_art.json` копируется в ресурсы приложения (например, `app/src/main/assets/pixel_art.json`) и разбирается один раз при запуске.

Отрисовка: общий компонент рисует спрайты в `ImageBitmap` логического размера (48 × 48 или 180 × 100) и переносит его `drawImage` с целым увеличением `floor(размер_в_px / логический_размер)` и `FilterQuality.None`, остаток — поля по центру. Он заменяет `drawPet` из `ui/common/PetArt.kt` и `drawScene` из `ui/common/SceneArt.kt`; размеры и рамку по-прежнему задаёт `PetFigure` в `ui/common/Components.kt`.

Где показывается:

| Экран | Что | Размер |
|---|---|---|
| `MainScreen` (`PetFigure(scene = true)`) | сцена в окне «… дома» на всю ширину карточки; палатка — при `house`; цель — выбранная цель копилки | по ширине карточки |
| `PetSetupScreen`, `WardrobeScreen` | фигура на карточке | до 140 dp (×8 на xxhdpi) |
| `SavingsScreen` | иллюстрация текущей цели 32 × 32 | целое увеличение |

Запуск реакций из `ui/state/GameViewModel.kt` — одноразовым событием (например, `SharedFlow<PetReaction>`), которое экран передаёт компоненту питомца:

| Метод и результат | Реакция |
|---|---|
| `buy(itemId)` → `PurchaseResult.Success`, товар с `category: needs` | `eat` |
| `buy(itemId)` → `PurchaseResult.Success`, товар с `category: wants` | `play` |
| `deposit(amount)` → `DepositResult.Success` | `save` |
| `answerTask(...)` → начислено больше нуля монет | `reward` |
| `finishPeriod()` → `PeriodCompletion.Success`, `outcome.stageAdvanced` | `grow` (до такта `swap_stage` рисуется `outcome.stageBefore`, после — `stageAfter`) |

Постоянное состояние и лицо выбираются по `StatLevel` заботы и радости питомца по таблице раздела «Выбор лица и состояния». Режим без анимации определяется по `ANIMATOR_DURATION_SCALE`; переключатель в приложении сейчас отсутствует и может быть добавлен полем в `DisplaySettings` (`ui/theme/Theme.kt`). В этом режиме событие реакции не запускается.
