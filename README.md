# Питомец Финни

Прототип мобильного приложения для Android по финансовой грамотности детей 7–11 лет. Разрабатывается для конкурса Департамента финансов города Москвы. Техническое задание и ответы организатора на вопросы команд в репозиторий не включены: это материалы организатора, и распространять их отдельно команда не вправе. Построчная сверка решения со всеми пунктами задания — в [docs/09-сверка-с-тз.md](docs/09-сверка-с-тз.md).

Текущая версия — 0.9.0 (versionCode 18). Ребёнок заботится о виртуальном питомце и распоряжается монетами. Игра идёт сезонами по три игровых дня; игровой день равен календарным суткам. В начале сезона приходят 50 монет, и ребёнок раскладывает их по трём направлениям — «Нужное», «Хочу» и «Копим на мечту»; план сезона можно поправить в любой момент. Покупки оплачиваются из свободных монет и запланированного на «Нужное» и «Хочу», копилка — только после подтверждения в окне «Не хватает монет». В сезоне девять событий, по три в день: голод в первый и третий день, жажда во второй, событие с покупкой, игра с питомцем и событие по времени года; два затратных события подряд не идут. Решение по событию сразу меняет баланс, копилку и самочувствие питомца и сопровождается объяснением; забота и радость питомца меняются только от решений ребёнка. После третьего дня экран «Итоги сезона» сравнивает план и факт полосами «План» и «Факт» и предлагает перевести остаток в копилку. С двора предмет «Игры» ведёт к выбору: «Сам» — задания по финансовой грамотности, «С {имя}» — игры с питомцем без монет и прогресса. Три задания, решённые за один заход в раздел заданий, открывают новую покупку в лавке (малышу — одна в игровой день, подростку и взрослому — две); монеты приносит задание «Помоги своему питомцу». Словарик устроен как игра с карточками: за каждый сыгранный игровой день открывается одна новая карточка термина. Предмет, о котором просит питомец в событии, сначала появляется в лавке. Питомец растёт за полученные мечты и решённые задания: подросток — 2 мечты и 9 заданий, взрослый — все 3 мечты и 18 заданий; полученная мечта показывается сценой, в которой питомец ею пользуется.

Проектные решения по игровой экономике, контенту и архитектуре — в [docs/01-проектные-решения.md](docs/01-проектные-решения.md).

Срок разработки по регламенту конкурса — 15.09–29.09.2026, далее предварительная экспертиза до 14.10.2026. ## Требования к окружению

- Windows 10/11, PowerShell.
- Интернет-доступ для первичной установки инструментов.
- Не требуется Android Studio — используется JDK 17 (Eclipse Temurin) и Android SDK command-line tools, устанавливаемые локально в `tools/`.
- Для проверки на физическом устройстве: смартфон или планшет с Android 8.0+ (API 26) и включённой отладкой по USB.

## Быстрый запуск (настройка окружения)

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-android-env.ps1
```

Скрипт скачивает и распаковывает JDK 17 и Android SDK (platform-tools, platform android-37.0, build-tools 37.0.0) в каталог `tools/` и принимает лицензии SDK. Файл `scripts/env.ps1` уже лежит в репозитории и пути вычисляет сам, поэтому скрипт его не трогает.

Перед сборкой в каждой новой сессии PowerShell:

```powershell
. scripts/env.ps1
```

Проверка, что окружение подключено:

```powershell
java -version   # OpenJDK 17.0.20.x Temurin
adb version     # Android Debug Bridge 1.0.41
```

## Сборка

Все команды выполняются из корня репозитория после подключения окружения (`. scripts/env.ps1`).

Отладочная сборка:

```powershell
./gradlew.bat assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Модульные тесты:

```powershell
./gradlew.bat test
```

Результат на версии 0.9.0 по отчётам JUnit (`*/build/test-results/**/*.xml`, коммит `40f2c50`): 311 тестов, отказов 0, ошибок 0, пропущено 0; по модулям — `core-economy` 66, `content` 85, `app` 153.

Релизная сборка:

```powershell
./gradlew.bat assembleRelease
```

Без файла `keystore.properties` (см. [docs/05-подпись-релиза.md](docs/05-подпись-релиза.md)) собирается `app/build/outputs/apk/release/app-release-unsigned.apk`. С заполненным `keystore.properties` — подписанный `app-release.apk`, готовый к установке без среды разработки (ТЗ 3.3).

### Зависимости

Состав релизной сборки закреплён файлом блокировок `app/gradle.lockfile`: все 117 разрешённых версий записаны явно. После добавления или обновления зависимости сборка остановится с сообщением `Resolved '…' which is not part of the dependency lock state`. Состояние пересобирается командой, после чего файл блокировок коммитится вместе с правкой:

```bash
./gradlew.bat :app:dependencies --configuration releaseRuntimeClasspath --write-locks
```

Перечень состава в формате CycloneDX и проверка на известные уязвимости по базе OSV:

```bash
python scripts/sbom.py
```

```bash
python scripts/audit.py
```
